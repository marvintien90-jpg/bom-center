# 顧問工作台（/consult/）

顧問專用的單一入口，和業主入口共用同一組 Supabase 登入（同網域，登入一次兩邊都通）。

- 權限：只有 `bom_profiles.role='admin'` 且 `status='active'` 才看到系統清單；業主與未登入只看到「只開放顧問使用／請先登入」。
- 業主入口 `portal/` 在管理員畫面上方多一張「顧問工作台」卡片，業主看不到。
- 系統清單在 `consult/index.html` 的 `GROUPS`，加一筆就多一張卡。
- 上方數字直接讀 `checkup_leads`（管理員 RLS 已允許）：新名單、逾期（新名單 ≥1 天、已聯絡 ≥3 天）、本月新健檢、累計成交。
- 測試：`node tests/consult.test.js`、`node tests/portal.test.js`。

## 2026-11-18 改版：串聯與美化

- **共用客戶主檔＝營運輔導客戶 `coach_clients`**（不用改資料庫）。其他工具已有欄位連到它：`org_plans.client_id`、`fr_plans.coach_client_id`、`sop_manuals.coach_client_id`；BOM／稽核／損益用 `coach_clients.brand_id`、`pl_client`；健檢用 `lead_id`。
- **工作台**：左側選單（Mac 桌面）＋今日要做（逾期名單、逾期輔導待辦、該訪視、稽核逾期）＋客戶旅程看板（健檢名單 → 洽談中 → 輔導中 → 暫停／結案）＋依流程排列的工具箱。點客戶開「客戶檔案」抽屜（`#c=ID`、名單 `#l=ID`），一眼看他在每個工具的進度，按「＋ 建立」自動帶入客戶。
- **共用元件 `consult/kit/kit.js`＋`kit.css`**：每個顧問頁最後載入 `Kit.init({tool, sb:sbc})`。
  - 跳出訊息 `Kit.toast()`；各頁原本的 `say()`（`#flash`）自動改成跳出訊息。
  - 按鈕波紋、懸浮、按下縮放、存檔中轉圈、上方讀取條、換頁淡入、數字跳動；尊重「減少動態效果」。
  - 客戶切換列：各工具頁最上方顯示目前客戶，並列出同一客戶在其他工具的連結（沒有的顯示「＋」）。新增畫面網址帶 `client=ID`（或營運輔導 `#new&lead=ID`）會自動帶入。
- **名單 → 輔導客戶**：名單頁每筆有「轉成輔導客戶 →」，營運輔導新增時帶入名稱與聯絡方式；以「輔導中」建立時名單自動標成「已成交」。
- 測試：`node tests/consult.test.js`（工作台、客戶檔案、切換列、帶入、轉換）。
